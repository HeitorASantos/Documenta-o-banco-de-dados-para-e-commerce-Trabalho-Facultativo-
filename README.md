Esse projeto foi desenvolvido no 2º semestre do curso de Ciências da Computação, focado na modelagem e estruturação de
um banco de dados relacional afim de suprir as necessidades de comércios digitais (como Amazon, Mercado Livre, Shopee, Shein, Aliexpress, entre outros) e de modelar de forma precisa como 
funcionaria um banco de dados dentro dessas companhias e como seria a forma mais eficiente de organiza-los.

---

## 📌 Visão Geral
Este repositório contém a documentação completa em formato pdf, com diagramas **lógico**, **físico** e **conceitual** do banco de dados projetado para suportar 
uma plataforma de e-commerce moderna e robusta. Além disso, contém exercícios resolvidos totalmente voltados para o nosso banco para responder quais requisições devem ser
feitas em diferentes cenários.

## 🛠️ Tecnologias e Ferramentas
* **SGBD Alvo:** MySQL
* **Ferramenta de Modelagem:** brModelo / MySQL Workbench / Draw.io

---

## 📜 Regras de Negócio Destacadas
* **Conta e Pedidos** Uma conta pode fazer nenhum ou vários pedidos e cada pedido é feito por exatamente uma conta.
* **Estoque e Produtos:** Os produtos possuem controle de estoque centralizado com integridade referencial para evitar vendas sem disponibilidade.
* **Integridade:** Uso estrito de restrições (`FOREIGN KEY`, `NOT NULL`, `UNIQUE`) para garantir a consistência dos dados em cenários transacionais.
